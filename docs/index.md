# Chalie Contributor Handbook

The single source of truth for contributing to Chalie — vision, principles, mechanics, and terminology. Human contributors and coding agents alike: start here, then load only what your task needs.

[MANIFESTO.md](MANIFESTO.md) is the one mandatory read. Route the rest by task:

| Your task | Read |
|---|---|
| First contribution | [MANIFESTO.md](MANIFESTO.md) — the vision and the twelve principles every change is judged against |
| Brainstorming / evaluating an idea | [MANIFESTO.md](MANIFESTO.md) Part I — the vision filter's three questions |
| Writing code | [MANIFESTO.md](MANIFESTO.md) P1–P12 + [CONTRIBUTING.md](CONTRIBUTING.md) — setup, layout, conventions |
| Fixing a bug | MANIFESTO P4 (fix the root, never the symptom) + [CONTRIBUTING.md](CONTRIBUTING.md) — a fix ships with the test that reproduces it |
| Writing or changing tests | [CONTRIBUTING.md](CONTRIBUTING.md) test tiers + MANIFESTO P11 (tests prove what a user would feel) |
| Reviewing a change | [MANIFESTO.md](MANIFESTO.md) Part III (the bar) + [CASE-LAW.md](CASE-LAW.md) — cite principles by number |
| Hitting an unfamiliar term | [VOCABULARY.md](VOCABULARY.md) — the system's terminology, one table |
| Anything security-adjacent | [SECURITY.md](SECURITY.md) — threat model, vault, tool execution, reporting |

Product and user documentation — setup guides, technical reference, the ability catalog — lives at [chalie.ai](https://chalie.ai), not in this folder.
