# Chalie Contributor Handbook

The single source of truth for contributing to Chalie — vision, principles, process, mechanics, and terminology. Human contributors and coding agents alike: start here, then load only what your task needs.

[MANIFESTO.md](MANIFESTO.md) is the one mandatory read. Route the rest by task:

| Your task | Read |
|---|---|
| First contribution | [MANIFESTO.md](MANIFESTO.md) — the vision and the twelve principles every change is judged against |
| Brainstorming / evaluating an idea | MANIFESTO Part I + [sdlc/brainstorming.md](sdlc/brainstorming.md) |
| Slicing approved work into tasks | [sdlc/task-breakdown.md](sdlc/task-breakdown.md) |
| Writing code | MANIFESTO P1–P12 + [CONTRIBUTING.md](CONTRIBUTING.md) + [sdlc/software-development.md](sdlc/software-development.md) |
| Fixing a bug | [sdlc/debugging-techniques.md](sdlc/debugging-techniques.md) + MANIFESTO P4 — a fix ships with the test that reproduces it |
| Writing or changing tests | [sdlc/qa-principles.md](sdlc/qa-principles.md) + [CONTRIBUTING.md](CONTRIBUTING.md) test tiers |
| Reviewing a change | [sdlc/technical-reviews.md](sdlc/technical-reviews.md) + MANIFESTO Part III + [CASE-LAW.md](CASE-LAW.md) — cite principles by number |
| Judging a release as a user would | [sdlc/product-reviews.md](sdlc/product-reviews.md) |
| Anything that holds state, fails, retries, or schedules | [sdlc/scalability-stability.md](sdlc/scalability-stability.md) |
| Anything a user sees or touches | [sdlc/ui-ux-principles.md](sdlc/ui-ux-principles.md) |
| Hitting an unfamiliar term | [VOCABULARY.md](VOCABULARY.md) — the system's terminology, one table |
| Anything security-adjacent | [SECURITY.md](SECURITY.md) — threat model, vault, tool execution, reporting |

The lifecycle spine — phase order, exit artifacts, the laws, and the drift protocol — is [sdlc/README.md](sdlc/README.md).

Product and user documentation — setup guides, technical reference, the ability catalog — lives at [chalie.ai](https://chalie.ai), not in this folder.
